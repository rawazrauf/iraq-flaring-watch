# Contributing to Iraq Flaring Watch

## Adding missing flares to the map

If you find a gas flare in Iraq that isn't on the map:

1. Create an OpenStreetMap account at [openstreetmap.org](https://www.openstreetmap.org)
2. Navigate to the flare location
3. Add a node with the tag `man_made=flare`
4. The map will pick it up on the next data refresh

## Reporting data issues

Open a GitHub issue if you notice:
- Incorrect population estimates
- Misassigned oil field names
- Broken plume images
- Economic calculation errors
